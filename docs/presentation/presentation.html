🛠️ Pipeline dell'Analisi — 6 Fasi

1Analisi 0-dimensionale: statistiche, covarianza, ECDF vs Gaussiana, heatmap correlazione
2Regressione lineare: costruzione algebrica di y = ax + b (minimi quadrati)
3Train/Test split: 90/10 con validazione oggettiva su dati mai visti
4Interpolazione: punto medio, problema inverso, estrapolazione, input interattivo
5Multilineare: y = Xθ con Equazioni Normali (linalg.solve)
6Outlier: loop interattivo di pulizia con residuo massimo

⛔ scikit-learn   ✅ numpy (algebra)   ✅ matplotlib   ✅ pandas   ✅ scipy.stats (solo CDF)

📐 Implementazione Algebrica

Regressione Semplice

a = Σ(xᵢ - x̄)(yᵢ - ȳ) / Σ(xᵢ - x̄)²
b = ȳ - a · x̄

Regressione Multilineare

θ = (XᵀX)⁻¹ Xᵀy

Risolto con numpy.linalg.solve per stabilità numerica

Covarianza Esplicita

C = (1/n) XcT Xc

Metriche da Zero

MSE = (1/n) eᵀe
R² = 1 − SS_res / SS_tot
